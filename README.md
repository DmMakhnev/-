# Архитектура МИС Пациента и Партисипативность

Интерактивное веб-приложение и презентационный прототип человекоцентричной ИТ-архитектуры здравоохранения (**МИС Пациента**). Проект наглядно демонстрирует переход от традиционных медицинских информационных систем ЛПУ и региональных ГИСЗ к партисипативной модели, где пациент является активным участником и основным владельцем собственных медицинских данных.

## 🌟 Ключевые возможности

- **Презентационный слайд (4:3)**: Наглядный архитектурный разворот с экспортом в **PowerPoint (.pptx)**, **PDF**, **PNG HD** и **SVG**.
- **Интерактивный прототип МИС Пациента**:
  - **Единый лист назначений (Раздел 6.1.2)**: Сводный планировщик терапии (15 постоянных препаратов из расписания + аварийные средства), журнал измерений, график процедур/манипуляций и календарь ВКС-консультаций.
  - **Наглядная визуализация результатов (Раздел 6.1.3)**: Динамика АД, глюкозы крови, массы тела и пройденных шагов за день с выделенным «коридором нормы» и маркерами событий коррекции доз.
  - **Персональный ассистент (Раздел 6.1.4)**: Уведомления, контроль приверженности и обратная связь по побочным эффектам.
  - **ИИ-Консультант (Раздел 6.1.5)**: Пояснение назначений понятным языком.
  - **Гранулярный контроль доступа (Раздел 6.3)**: Управление правами просмотра данных для врачей и сторонних организаций.
- **Сравнение парадигм**: Интерактивная матрица различий МИС ЛПУ, ГИСЗ и МИС Пациента.
- **Полный текст статьи и ТЗ**: Текстовые материалы для монографий, статей и нормативных спецификаций.

## 🛠️ Технологический стек

- **Frontend**: React, TypeScript, Vite
- **Стилизация**: Tailwind CSS, Lucide React Icons
- **Экспорт материалов**: `pptxgenjs`, `html2canvas`, `jspdf`
